# Magic-Shoe-Sensors-For-Blind-People-Using-IoT
magic shoes sensor for visually impaired person 
Navigating everyday environments is challenging for visually impaired individuals, as 
traditional white canes provide limited obstacle detection. To overcome this problem, the 
proposed IoT-based “Magic Shoe” helps detect obstacles in advance and improves user 
safety and independence.
The system uses an HC-SR04 ultrasonic sensor to detect obstacles, while the Arduino 
UNO and NodeMCU (ESP8266) process sensor readings. When an obstacle is detected 
within a predefined distance, a buzzer alerts the user. The NodeMCU uses Wi-Fi to send 
data to an IoT platform such as Blynk or ThingSpeak, enabling remote monitoring by 
caregivers.
The system is designed to be portable, affordable, and easy to use. It can help reduce 
collisions and improve mobility. Future enhancements may include GPS tracking, voice 
alerts, and vibration feedback.
